# smart-home-ai — Camera AI Thông Minh

Biến một camera thường thành "người trông nhà" có AI: nhận ra người nhà, báo người lạ, nhớ chỗ để đồ, phát hiện té ngã và trả lời câu hỏi bằng tiếng Việt. Toàn bộ xử lý hình ảnh chạy trên máy trong nhà.

Đặc tả đầy đủ: [docs/SPEC.md](docs/SPEC.md). Biên bản nghiệm thu: [docs/acceptance/](docs/acceptance/).

> README đầy đủ được hoàn thiện ở GĐ 6.
